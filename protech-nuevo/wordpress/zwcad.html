Preguntas frecuentes

Antes de comprar ZWCAD

¿Cómo funciona la licencia perpetua?

Haces un solo pago y la licencia es tuya para siempre. No hay cuota anual obligatoria para seguir usando el software.

¿Si compro la licencia, recibo las versiones nuevas?

Cada año ZWSOFT lanza una versión con nuevas funciones. Para pasar a ella se compra una actualización (upgrade), pero no es obligatoria: puedes seguir trabajando con tu versión el tiempo que quieras.

¿Puedo usar ZWCAD y AutoCAD® al mismo tiempo?

Sí. Pueden instalarse en el mismo equipo sin conflictos y ambos trabajan sobre el formato DWG.

¿Es compatible con mis archivos de AutoCAD®?

Sí. ZWCAD abre archivos DWG de versiones recientes de AutoCAD® (2023, 2024, 2025, 2026). Al guardar puedes elegir la versión de DWG (2018, 2013, 2010, 2007, 2004, 2000 y R14) y de DXF, para compartir con clientes que usan versiones anteriores.

¿Qué compatibilidad tiene con software BIM como Revit?

ZWCAD importa archivos IFC, el formato estándar de intercambio BIM.
